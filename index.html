A filename is not proof of authenticity

03

Review installation permissions narrowly

Android may temporarily allow the browser or file manager to install a verified APK. Grant permission only to the source used for the download and turn it off after installation. A package that asks for unrelated contacts, messages, photos or accessibility access deserves additional scrutiny.

04

Protect login and recovery codes

A one-time code authorises a specific action. Do not forward it to an agent, mentor, support account or screen-sharing caller. If an unexpected code arrives, stop the process, review account activity and use the recovery route linked from the main Group C domain.

Recognise fake payment support
